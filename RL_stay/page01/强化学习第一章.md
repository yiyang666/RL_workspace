# 1.1 什么是强化学习

强化学习的核心问题：

> 智能体（Agent）如何在环境（Environment）中通过试错获得最大长期收益。

它和监督学习最大的区别：

| 监督学习   | 强化学习   |
| ------ | ------ |
| 数据集固定  | 数据来自交互 |
| 有标准答案  | 没有标准答案 |
| IID 数据 | 时序相关数据 |
| 预测正确即可 | 需要长期决策 |

典型强化学习流程：

```text
Agent --action--> Environment
Agent <--state,reward-- Environment
```

强化学习的关键：

* 当前动作会影响未来数据分布
* 延迟奖励（Delayed Reward）
* 探索（Exploration）与利用（Exploitation）

---

# 1.2 强化学习核心元素

一个标准 RL 系统包含：

| 元素               | 含义   |
| ---------------- | ---- |
| State s          | 环境状态 |
| Action a         | 动作   |
| Reward r         | 奖励   |
| Policy π         | 策略   |
| Value Function V | 状态价值 |
| Q Function       | 动作价值 |
| Environment      | 环境   |

例如机器人控制：

| 项      | 示例          |
| ------ | ----------- |
| state  | 关节角度、速度、IMU |
| action | 电机 torque   |
| reward | 前进速度、稳定性    |
| policy | 神经网络        |

对于你的背景（机器人算法），后面会经常遇到：

* proprioception
* torque control
* locomotion reward
* sim2real
* trajectory optimization

这些最终都可以映射到 RL 框架。

# 1.3 马尔可夫决策过程（MDP）

强化学习最核心的数学模型：

MDP（Markov Decision Process）

定义为五元组：

$$
(S, A, P, R, \gamma)
$$

其中：

| 符号 | 含义     |
| -- | ------ |
| S  | 状态空间   |
| A  | 动作空间   |
| P  | 状态转移概率 |
| R  | 奖励函数   |
| γ  | 折扣因子   |

---

## 马尔可夫性质

未来只与当前状态有关：

$$
P(s_{t+1} \mid s_t) = P(s_{t+1} \mid s_1, s_2, \ldots, s_t)
$$

即：

> 当前状态已经包含了所有历史信息。

机器人里非常重要。

例如：

* 只有图像时：可能不是 MDP，因为单帧图像缺失信息，看不出力/接触，遮挡、模糊时，同一画面可能对应多种真实局面
* 加入速度、IMU 后：更接近 MDP

因此很多机器人 RL 的 observation 设计，本质是在“逼近马尔可夫性”。
> **理解笔记**：图像常是部分观测；加上速度、IMU 等是在把观测补全到更接近真实动力学状态，从而让 RL 里常用的「马尔可夫假设」更合理。

---

# 1.4 Return（累计回报）

强化学习优化的不是单步 reward。

而是长期回报：

$$
G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + ...
$$

这里：

* γ 越大：越关注长期收益
* γ 越小：越短视

常见设置：

| 场景    | γ          |
| ----- | ---------- |
| Atari | 0.99       |
| 机器人控制 | 0.99~0.999 |
| 短任务   | 0.9        |

---

## 为什么需要 γ

如果没有折扣：

* 无限 horizon 可能发散
* 数学不稳定
* Bellman Equation 不一定收敛

强化学习很多理论成立都依赖：

$$
0 < \gamma < 1
$$

---

# 1.5 Value Function

价值函数用于评估：

> 一个状态“有多好”。

定义：

$$
V^\pi(s)=\mathbb{E}_\pi[G_t|s_t=s]
$$

含义：

> 在策略 π 下，从状态 s 出发，未来累计奖励的期望。

---

# 1.6 Q Function（动作价值函数）

更重要的是：

$$
Q^\pi(s,a)=\mathbb{E}_\pi[G_t|s_t=s,a_t=a]
$$

Q 的意义：

> 在状态 s 下执行动作 a 的长期价值。

强化学习大部分算法最终都在学习 Q 或其变体。

例如：

* DQN
* Double DQN
* SAC
* TD3

都与 Q-function 强相关。

---

# 1.7 Bellman Equation

强化学习最核心公式。

## Bellman expectation equation

$$
V^\pi(s)=\sum_a\pi(a|s)\sum_{s',r}P(s',r|s,a)[r+\gamma V^\pi(s')]
$$

其本质：

> 当前价值 = 当前奖励 + 下一状态价值

动态规划的核心思想。

---

## Bellman Optimality Equation

最重要版本：

[
Q^*(s,a)=\mathbb{E}[r+\gamma \max_{a'}Q^*(s',a')]
]

这是 Q-Learning 的理论基础。

后面 DQN 本质就是：

* 用神经网络拟合 Q
* 用 Bellman Equation 做 bootstrap

---

# 1.8 Temporal Difference（TD）思想

TD Learning：

> 用自己的未来估计更新自己。

TD error：

[
\delta = r + \gamma V(s') - V(s)
]

如果：

* δ > 0：比预期好
* δ < 0：比预期差

强化学习很多算法本质都在最小化 TD error。

包括：

* DQN
* Actor-Critic
* PPO
* SAC

---

# 1.9 Monte Carlo vs TD

| 方法          | 特点           |
| ----------- | ------------ |
| Monte Carlo | 等 episode 结束 |
| TD          | 每一步更新        |

TD 更适合：

* 在线学习
* 长序列
* 机器人控制

因为机器人不可能等“人生结束”再学习。

---

# 1.10 Q-Learning

经典离策略（Off-policy）算法。

更新公式：

[
Q(s,a) \leftarrow Q(s,a)+\alpha[r+\gamma\max_{a'}Q(s',a')-Q(s,a)]
]

其中：

| 符号    | 含义            |
| ----- | ------------- |
| α     | learning rate |
| γ     | discount      |
| max Q | greedy target |

其本质：

```text
新Q = 旧Q + 学习率 × TD误差
```

---

# 1.11 Off-policy vs On-policy

这是 RL 的超级重点。

## On-policy

用当前策略产生数据。

例如：

* SARSA
* PPO
* A2C

特点：

* 稳定
* 数据利用率低

---

## Off-policy

可以用历史数据。

例如：

* Q-learning
* DQN
* SAC
* DDPG

特点：

* sample efficient
* 更复杂
* 更容易不稳定

机器人强化学习里：

Off-policy 很重要。

因为真实机器人采样成本极高。

---

# 1.12 Exploration vs Exploitation

强化学习核心矛盾：

| 行为           | 含义     |
| ------------ | ------ |
| Exploration  | 探索未知   |
| Exploitation | 利用当前经验 |

典型方法：

## ε-greedy

[
\pi(a|s)=
\begin{cases}
随机动作 & \epsilon \
argmaxQ(s,a) & 1-\epsilon
\end{cases}
]

DQN 经典方案。

# 1.15 编写第一个 Q-learning

先离散化状态。

```python
import gymnasium as gym
import numpy as np

env = gym.make("CartPole-v1")

n_bins = 20

q_table = np.zeros((20,20,20,20,2))
```

---

## 状态离散化

```python
state_bounds = list(zip(env.observation_space.low,
                        env.observation_space.high))

state_bounds[1] = (-0.5, 0.5)
state_bounds[3] = (-math.radians(50), math.radians(50))
```

---

## ε-greedy

```python
if np.random.random() < epsilon:
    action = env.action_space.sample()
else:
    action = np.argmax(q_table[state])
```

---

## Q update

```python
best_next = np.max(q_table[next_state])

td_target = reward + gamma * best_next

td_error = td_target - q_table[state][action]

q_table[state][action] += lr * td_error
```

# 1.16 为什么 Tabular Q-learning 不够

因为现实问题状态空间巨大。

例如机器人：

```text
state dimension > 100
```

Q-table 会直接爆炸：

[
|S|\times|A|
]

于是进入：

# Deep Reinforcement Learning

即：

> 用神经网络近似 Q function

这就是 DQN。
